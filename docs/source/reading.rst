.. _reading:

Reading an RSM page
===================

An RSM page reads like a paper, and the reader can also look up references
without losing their place, fold and open parts of it, follow how a proof
fits together, and set the type to suit them. The examples on these pages are
RSM pages, so each feature can be tried there.

.. _reading:

Reading an RSM page
===================

An RSM page reads like a paper. A reader can also fold and open parts of it,
read the statement of a result without leaving the current one, follow how a
proof fits together, and change the type to suit them. These pages show what
a reader can do, and the examples on them are RSM pages where each feature
can be tried.

Some features depend on how the author built the page. The sidebar, and the
features that live in it, are on a page built with ``rsm build --sidebar``.
Each page below says when a feature needs the sidebar.

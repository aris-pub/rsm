.. _contributing:

Contributing
============

RSM welcomes contributions of any size.


Ask a question
--------------

Search the `discussions <https://github.com/aris-pub/rsm/discussions>`_ for a
similar question first. If there is none, `start a discussion
<https://github.com/aris-pub/rsm/discussions/new>`_.


Ask for a feature
-----------------

`Start a discussion <https://github.com/aris-pub/rsm/discussions/new>`_ that
describes what you want to do and why.


Report a bug
------------

`Open an issue <https://github.com/aris-pub/rsm/issues/new>`_ with the RSM
source that shows the bug, what you expected and what happened. If you are not
sure that it is a bug, start a discussion instead.


Change the docs or the code
---------------------------

Send a pull request to the `repository <https://github.com/aris-pub/rsm>`_.
:ref:`how-rsm-works` explains the steps from source to page, and the Python
modules that make each one.
